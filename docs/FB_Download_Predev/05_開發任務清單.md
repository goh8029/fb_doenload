## 專案理解
Windows Chrome MV3 擴充功能，另開真正的 FB 工作分頁、保留原頁，加入工具列、卡片勾選及側欄，不使用 iframe。沿用官方登入，不收帳密／Cookie，不設後端或 DB；詳細索引與快照用授權目錄中的 JSON。

一鍵完整下載每次建立新批次，保留舊檔；勾選下載核對索引與實體檔，僅跳過同媒體同品質且可信完整的檔案。父層全選包含未載入子項，可依關聯排除個別媒體；同目標保留選取，不同目標隔離。跨分類共用媒體取得，但各目的路徑獨立記錄結果。最後確認後凍結目標與選取。

目前只有設計，沒有實作或通過證據。P0 必須驗證真實 FB 身份、分類、目錄授權、照片／有聲影片串流、檔案提交與中斷恢復。未通過不進入完整功能開發。可見不等於工具支援；Reels、動態、精選不可預設可用。核心假設失敗先提出方案，改需求再由使用者決定。

四份原文件已在本目錄，04 的「尚未放入 D 槽」為歷史敘述。其引用的 Facebook_Downloader_Spec_v1.md 未在本資料夾找到，本清單僅依實際讀到的四份文件。原文件的需求與設計內容保留，僅調整檔名及文字用語。
