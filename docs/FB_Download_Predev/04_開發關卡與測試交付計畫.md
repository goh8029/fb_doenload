## 4 測試方法
單元：選取、命名、去重、狀態機、重試及進度。整合測試資料：可控延遲、失敗、串流。真實 Chrome 載入擴充功能驗證，Playwright 自動化能力 P0 確認。

記錄 Windows、Chrome、程式版本、CPU／RAM、磁碟、網路、日期、樣本數與 p95 測量起訖。真實 FB 僅必要少量授權資料，由使用者自己登入；帳密、Cookie、私人媒體及驗證 URL 不入報告或 Git。不能用固定 Mbps 作來源服務保證。
